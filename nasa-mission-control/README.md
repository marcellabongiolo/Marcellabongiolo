# NASA Mission Control 🚀

A front-end mission operations dashboard created as a Software Engineering portfolio project.

## Overview

**NASA Mission Control** is a responsive interface that simulates a spacecraft operations console. It presents mission status, orbital telemetry, active missions and a live-updating telemetry chart.

The project intentionally starts with simulated data so the interface can be developed independently from external services. It can later be extended with real NASA APIs.

## Features

- Responsive mission-control interface
- Mission status cards
- Orbital visualization using CSS
- Simulated telemetry
- Live UTC clock
- Dynamic telemetry chart with Canvas
- Mobile-friendly layout
- No build step required

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Canvas API
